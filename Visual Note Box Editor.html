轨道 / 乐器

乐器：
左键/拖拽=添加音符　右键或Shift=擦除音符　空格=播放/暂停　Ctrl+Z=撤销　Ctrl+Y=重做

网格

导出 mcfunction 数据包
安装步骤
1. 下载数据包
2. 将数据包放入"版本名称/世界名称/datapacks"
3. 进入世界后输入 /reload
4. 输入 /function noteblk:init 放置机器
5. 输入 /function noteblk:play 播放，/function noteblk:stop 停止
